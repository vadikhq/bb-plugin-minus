# Служебные Thought в одной сводке инструментов

## Принятый scope

Владелец показал повторные цитаты между видимыми Thought. Прежняя установленная редакция объединяла только DOM-соседние инструменты через не смонтированное reasoning. Адресная fixture воспроизвела пять сводок вместо одной. После merge PR #1 владелец ответил «да» на новую ветку `bb/minus-visible-thoughts` от свежего origin/main и предложенное поведение: служебные Thought входят в раскрываемые подробности той же сводки, полезные сообщения агентов остаются снаружи. Ветка создана в прежней папке от `9bf014f9c594f79d6d95734152f755fd03bfb666`; прежняя ветка и untracked материалы сохранены.

Основа оформления — [принятая редакция от 31 октября](2026-10-31-quote-flood.md), кольцо/точка, стрелка, native серый, отступы и разделители. Это изменение состава одной существующей сводки; последующее уточнение оформления владельцем записано ниже. Значки, словарь и API BB не меняются. Далио ведётся отдельным подтредом; его материалы и quotes.ts в эту правку не входят. Settings — существующая секция Minus и collapseToolCalls; нового входа в rails не требуется.

## Наблюдаемый результат

Подтверждённые API служебные строки system/reasoning со статусом pending/completed раскрываются вместе с соседними инструментами. В счётчик и итоговое время входят только уникальные инструменты. Пока размышление или инструмент выполняется, кольцо активно, время отсутствует. Неизвестные строки, ошибки, остановки, сообщения и дочерние потоки сохраняют видимость и границы. Пустой блок из одних размышлений не создаёт цитату.

## Локальная редакция и проверки

`reasoningDetail` принимает только подтверждённые текущим API system/reasoning со статусом pending/completed без message или child timeline. API index по-прежнему считает только work; сводка объединяет их уникальные IDs и читает состояние связанных Thought отдельно. Во время pending время скрыто, завершённые Thought не добавляют длительность. При отсутствии доказательств API строки остаются видимыми; ошибки и остановки не маскируются.

Независимое ревью первой локальной редакции нашло P2: удаление pending Thought из DOM преждевременно объявляло цикл завершённым. Исправлено до публикации: сохраняется подтверждённая идентичность Thought, а её текущее состояние восстанавливается по API-соседству с work members в том же sibling source. Обход останавливается на conversation/work/unknown границах; ранее обнаруженное полезное содержимое защищено visibleRows и после unmount. Отдельные removal/reinsert/terminal регрессии и независимые адресные пробы подтвердили исправление.

[101 тест](verification/2026-10-31-visible-thoughts/tests.xml), strict TypeScript и build прошли на source hashes первой редакции; итоговая редакция проверена ниже. Двенадцать [browser contexts](verification/2026-10-31-visible-thoughts/browser.json) проверяют 320/390/1280 px, текст 100/200%, light/dark, pending Thought, его unmount/reinsert, terminal и Enter/Space. Все восемь tools и пять Thought раскрываются одной кнопкой, оба сообщения снаружи, общий итог инструментов 68s → 1m 08s. Это синтетические данные по паттерну скриншота. Двенадцать PNG сняты local-ui-capture; desktop open — viewport crop, узкий open содержит полную группу.

## Настоящий frontend кандидата

[Адресный native прогон](verification/2026-10-31-visible-thoughts/native-candidate.json) прошёл в четырёх contexts: установленный baseline и candidate на 1280/390 px. Это настоящий смонтированный завершённый этап, unmodified timeline API; кандидатские JS/CSS подставлены только в disposable isolated headless Chromium. Рабочий source/bundle до и после прежние; установка не выполнялась.

Старый baseline даёт пять цитат [1,1,2,1,1] с шестью открытыми Thought-разделителями. Кандидат даёт две сводки: 5 tools · 976ms и 1 tool · 30ms. Между ними настоящий delegation, поэтому объединять всё в одну сводку нельзя. [Независимый пересчёт API](verification/2026-10-31-visible-thoughts/api-metrics.json): 334+215+29+115+283=976ms, отдельно30ms; итого6уникальных tools/1006ms. Все шесть Thought скрыты при закрытии, видимы после Enter на обеих группах и снова скрыты после Space. Полезные сообщения и delegation остаются видимыми; overflow и browser errors отсутствуют. Приватные thread/member IDs в опубликованной квитанции заменены стабильными псевдонимами; исходный read-back сохранён локально для независимого reviewer.

Первый native прогон завершился timeout: выбранный исторический t1 отсутствовал в текущем mounted window, где доступны t18–t20. Его PASS не считаем. Следующая диагностическая попытка ожидала одну сводку, но API показал настоящую delegation-границу: две сводки корректны. Ошибку ожидания исправили в harness, source при этом не менялся. Окончательный прогон сверяет состояние с независимыми API-группами и успешно проверяет обе ширины и переключения.


## Дополнение владельца: обычный текст и разделители

Во время проверки владелец уточнил: «ещё часто цитаты с форматированием цитаты появляются что не прикольно, либо всё с цитатой и без дивайдеров либо строго дивайдеры без форматирования quote». Из двух разрешённых вариантов исполнитель сохранил уже принятые разделители/поля и выбрал обычный серый текст. Содержание цитат и русское авторство не меняются; форматирование quote/курсив отсутствует.

В последней редакции TOGGLE_HTML у data-quote заменён только italic на native not-italic. Inline CSS, остальные classes, поведение и символы прежние. Это отменяет прежний курсив только в сводке Minus; Markdown-оформление полезных сообщений агентов не меняется. Все прежние решения о сером, inline-источнике без ссылки, ширине, отступах, значках и итоговом времени сохранены.

Доказательства выше относятся к первоначальному кандидату Thought до этого уточнения и хранятся как история. Текущие source hashes, тесты, browser/native JSON и PNG оформляются отдельно в verification/2026-10-31-visible-thoughts/plain/. Первый plain-кандидат `658f3b6e` отличался от проверенной reviewer редакции `94cd592` классом обычного начертания и одним guard: native `work-summary`, чей первый API ID является reasoning, не классифицируется как отдельный Thought. Иначе терялся состав инструментов этой пачки. В окончательной редакции также исправлен описанный ниже P2 активности native summary; [проверка сравнения](verification/2026-10-31-visible-thoughts/plain/style-comparison.json). Inline CSS совпадает, generated Tailwind CSS побайтно отличается; его итоговый артефакт проверен новой browser-матрицей.

## Замечание независимого ревью и его исправление

На plain-кандидате `658f3b6e` reviewer подтвердил P2: если внутри native summary pending reasoning, а все work завершены, сводка преждевременно показывала completed и время. Прежние тесты pending-summary делали pending инструмент, а не reasoning. Кандидат не публиковался и не устанавливался.

Окончательная логика сохраняет подтверждённый API-span summary вместе с reasoning, затем отдельно выделяет work для count/time и service reasoning для activity. После header count берётся только непосредственно следующее reasoning до следующего work/message/interaction либо следующей смонтированной строки. Полезное содержимое и sibling boundaries сохраняют защиту. Регрессии проверяют pending reasoning до/между/после завершённых tools, terminal-переход без потери раскрытия и независимую следующую summary за virtualization spacer. Два дополнительных browser-контекста проверяют настоящее вращение кольца и отсутствие времени при pending reasoning внутри synthetic native summary.


[Итоговое независимое ревью](verification/2026-10-31-visible-thoughts/plain/independent-review.json) сняло P2 на source `e170b1ad` / tests `d6edbda01`: семь адресных проб, все 12 PNG и final evidence проверены; новых P0/P1/P2 в ограниченном объёме не обнаружено. Полный suite reviewer не повторял. Словарь и рабочая установка не менялись.
