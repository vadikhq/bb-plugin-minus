# Установка словарей цитат

Владелец может выбирать подборку в Settings → Plugins → Minus → «Словари цитат». По его поручению активирован отдельный Далио (452 цитаты); прежняя философская подборка (73 записи) сохранена. Подпись в реальном чате показывает цитату → Рэй Далио → главу обычным серым текстом. Реализован native tool `minus_dictionaries` для добавления словарей агентами; импорт не активирует набор автоматически. Бон и Хормози не импортированы.

## Применённая версия

Установлен точный проверенный источник `git:https://github.com/vadikhq/bb-plugin-minus.git@48d3ffb1de14f725a9b5cbacdc74ba0d2224ed22`, bundle `01adc6d58bab3125`. Штатное install job `8065ef87-0a34-45d5-8690-06c26eb4d2ba` завершилось `succeeded`. [Read-back и результаты живого сценария](verification/2026-10-31-quote-dictionaries/installed.json) связаны с [локальными проверками и scope](2026-10-31-quote-dictionaries.md).

Перед заменой отдельно прочитаны source/bundle, config, jobs, status/errors и данные. Очереди были пусты, старый backend объявлял только 31 boolean setting; secrets, schedules, services и сохраняемых данных не использовал. Снимок настроек сохранён, прежний Git object проверен через remote. После штатных remove/install возвращено `collapseToolCalls=true`; все 31 прежних значения совпали, новая настройка `quoteDictionary=dalio` подтверждена отдельно. Общий BB runtime не останавливался, SDK/core/vendor/cache вручную не менялись, независимый Thought PR не затронут.

## Проверка установленного интерфейса

Изолированный headless Chromium открыл настоящий установленный frontend напрямую, без proxy, подмены bundle или fixture RPC. На ширинах 1280 и 390 доступны оба набора с правильными количествами. Проверено переключение к прежнему набору, сохранение после reload, возврат к Далио и повторный reload. На каждой ширине наблюдалось по семь групп реального треда: только Далио и глава, обычное начертание, без горизонтального переполнения. Keyboard focus виден, page errors отсутствуют. PNG настроек и текущего чата просмотрены; приватные снимки чата в публичный Git не включены.

Первый запуск headless был отклонён sandbox на macOS MachPortRendezvous; процесс завершился. Повтор по разрешённому локальному маршруту успешен. При завершении первого UI-стенда лишний запрос с неверным wrapper был отклонён валидацией, данные не изменились. Стенд исправлен, перезагружен только Minus, затем повторены живой сценарий и отдельный read-back. Финальное состояние: enabled/running, statusDetail=null, ошибок нет; source/bundle неизменны, очередь пуста. Отказы не засчитывались как успешная проверка.

Установленные исполняемые файлы совпали с независимо проверенными SHA-256. SHA-256 загруженного JS `e6a15b23798868e299508b5d950a97b29b96f9fb64428f1c48eb464e5174196a` совпал с визуально проверенным кандидатом. Native agent-tool registration присутствует в host; горячее появление инструмента во всех уже работающих provider sessions не заявляется.

## Сохранность и остаток

Migration штатно создала базу плагина; пользовательских словарей сейчас ноль. Это не разрешает игнорировать базу при следующем обновлении. Будущему remove обязательно предшествует проверяемое сохранение и восстановление актуальных словарей, настроек и прочих данных. Прежний exact source `eb5f9157786c412ebf2a26fa48641617a6b53400` сохранён в Git как обратный источник; откат в этом ходе не выполнялся.

Исполняемая версия установлена из commit `48d3ffb…`; последующие документационные коммиты не меняют её байты. Merge не выполнялся. Готовый текст PR показан владельцу для отдельного согласования. Полная пользовательская приёмка и редакторский фильтр Хормози остаются открытыми решениями.
