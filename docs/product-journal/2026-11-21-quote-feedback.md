# Скрытие цитат и вычитка

21 ноября 2026. В существующее меню Minus добавлены «Скрыть из показа» и «Плохая цитата». Первый пункт исключает цитату из следующих подборов. Второй сохраняет текст и источник на вычитку и тоже исключает её из следующих подборов. Владелец выбрал скрытие до вычитки. Уже показанный текст сохраняется. В настройках две отметки можно снять независимо.

## Интерфейс

Пункты добавлены между копированием и настройками на основе [принятого меню справа сверху](2026-11-04-quote-actions.md). Сердце, счётчик и раскрытие остаются на своих местах. Для строк действий применены существующие цвета, шрифты, отступы и иконки того же веса. Подписи и доступные имена заданы на английском и русском. Контролы доступны с клавиатуры. Фокус прокручивает список внутри меню, если высоты не хватает.

Настройки → Плагины → Minus → «Действия с цитатой» показывает скрытые и помеченные цитаты с источником. У каждого списка своя отмена. При двух отметках цитата вернётся в подбор после снятия обеих. Точка входа «Настройки Minus» осталась в меню цитаты.

## Хранение и отбор

Две отметки хранятся добавочной миграцией по ID словаря, цитаты и действия. Сохранённый текст пометки переживает правку словаря. Запись идемпотентна, подтверждается отдельным чтением. Остальные клиенты получают обновление списка пометок по тегу RPC без инвалидации словарей и избранного.

Фильтр пересчитывается при новой редакции списка. Обход ленты для этого не нужен. Уже показанные цитаты и раскрытия сохраняются. Когда список недоступен либо все цитаты исключены, показывается счётчик с раскрытием. Восстановленное чтение разрешает выбор для новых групп. История лайков сохраняет прежнюю модель данных.

## Test scenarios

- [x] Скрыть и пометить одну цитату, перезагрузить, снять лишь одну отметку. Вторая продолжает исключать цитату. Избранное, словари и выбор словаря сохраняются.
- [x] Выполнить пометку при задержке, повторном нажатии и ошибке. Размер меню, уже показанный текст, фокус, положение сводки и раскрытие устойчивы.
- [x] Исключить весь словарь. Раскрыть инструменты в строке со счётчиком. После отмены скрытия новая группа получает цитату, прежняя строка сохраняется.
- [x] Воссоздать сбой первого чтения. Счётчик доступен при сбое. В настройках чтение можно повторить.
- [x] Проверить узкую русскую тёмную и широкую английскую светлую раскладки. В меню с ограниченной высотой клавиатура прокручивает нужный пункт, Escape возвращает фокус.

164 теста, TypeScript и штатная сборка прошли. Кандидат JS/CSS проверен в нативном BB в изолированном Chromium на 1280 и 390 px. RPC Minus шли в тестовый SDK и отдельную SQLite. Остальные HTTP-записи и WebSocket заблокированы. Действующая сборка совпала до и после. Ошибку и восстановление чтения в одной ленте проверили по коду и устойчивости счётчика при изменении выбора. В браузере восстановление проверено через настройки.

`bb-plugin-workflow` и `bb-plugin-authoring` сверены с принятым поведением, SDK и жизненным циклом. `impeccable` и `frontend-design` применены к размерам меню, состояниям, фокусу и настройкам. Независимое дизайн-ревью повторено после исправлений. Открытых P2 на финальных байтах нет. Пин SDK 0.6.79 сохранён.

Редакция словаря Бон ведётся отдельным частным пакетом. Эта ветка содержит изменения Minus и тесты, пригодные для публикации без материалов лекций. До установки рабочая версия и данные остаются на прежнем источнике.
