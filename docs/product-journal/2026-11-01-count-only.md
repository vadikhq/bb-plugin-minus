# Одна сводка инструментов без внешней рамки и подсчёта времени

Владелец прислал два снимка: служебные Thought разбивали непрерывный блок на повторные цитаты, а этап без обычного сообщения сохранял внешнюю рамку Worked for вокруг разделителей Minus. Прямое решение: полностью удалить подсчёт времени тулколов, устранить двойное оформление, сделать компактнее без лишних переносов и скачков; провести независимое ревью в подтреде и установить обновление. Разрешение на установку относится к этой редакции; merge не поручен. Сохраняемые лайки остаются отдельной функцией на стадии макета.

Основа интерфейса — принятые [одна сводка](2026-10-31-quote-flood.md) и [объединение Thought](2026-10-31-visible-thoughts.md). Новое решение отменяет прежний показ итогового времени. Цвета, обычное начертание, раскрытие инструментов и видимость сообщений, workflow/delegation и пользовательского ввода сохраняются. Количество и стрелка теперь образуют один неразрывный inline-flex контроль; цитата и автор разделены средней точкой.

## Реализация

- Удалены durationMs, суммирование времён, форматирование единиц, чтение startedAt/completedAt, DOM для времени, подсказки и aria-текст о времени. Clock остаётся только для прежнего ограничения частоты API-запросов, анимации статуса не используют длительность вызовов.
- Подтверждённые служебные Thought входят в одну сводку соседних инструментов. Статус остаётся активным до завершения соответствующего цикла; полезный стрим и неизвестные/ошибочные строки защищены.
- Неизменённый уже проверенный virtualization spacer сохраняет соединение при повторном чтении; новый/изменённый промежуток требует свежего доказательства. Этот фикс ранее проверен отдельно и включён в текущий scope стабильности сводки.
- Внешний turn распознаёт собственные инструменты через уже защищённую mixed work-summary. Чужой delegated nested timeline не становится собственным инструментом. Прежняя безусловная граница по measure row/root сохранена.
- Собственный список получает обратимый `data-bb-minus-flat-list`: снимаются только его padding/margin и псевдолиния. Его display:flex, gap и измеряемый блок сохраняются. При отключении/cleanup атрибут снимается вместе с остальным оформлением.
